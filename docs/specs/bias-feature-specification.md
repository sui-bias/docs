# Bias 기능 명세서

## 작성 원칙

모든 기능 행은 요청된 순서인 대분류 / 소분류 / 기능 이름 / 설명을 따른다. 설명은 기술 구현 방식이 아니라 사용자가 실제로 이용하는 기능, 입력값, 결과값, 예외 상황을 중심으로 작성한다.

## 제품 프레이밍

Bias는 연예인 또는 AI가 일방적으로 발화하는 버블형 앱이 아니라, 사용자가 자신만의 캐릭터와 함께 1:1 또는 단체 대화에 참여하는 관계형 채팅 앱이다. free 사용자는 플랫폼이 제공하는 캐릭터만 사용할 수 있고, plus 사용자는 직접 만든 캐릭터를 최대 2개까지 보유할 수 있다. 단체채팅은 MVP 기준 사람 최대 2명, 캐릭터 최대 2개가 함께 참여하는 2:2 구조를 기본으로 한다.

## 제품 결정 (확정)

| 항목 | 결정 |
| --- | --- |
| 캐릭터 소유 | plus 이상 사용자는 직접 만든 캐릭터를 본인 소유 캐릭터로 사용할 수 있고, free 사용자는 플랫폼 제공 캐릭터만 사용할 수 있다. |
| 온보딩 게이트 | 가입과 프로필 초기화가 끝난 뒤 free는 제공 캐릭터 선택으로, plus는 캐릭터 생성 페이지 또는 제공 캐릭터 선택으로 진입한다. |
| BM/요금제 | free는 캐릭터 생성이 불가하고 제공 캐릭터 기반 1:1 chat과 제한된 group chat을 사용할 수 있으며, plus는 캐릭터 생성 최대 2개를 제공한다. |
| 캐릭터 자율 발화 | group chat에서 사용자는 일반 단체 채팅처럼 자유롭게 대화하고, 캐릭터는 대화 흐름을 보고 상황에 맞을 때 스스로 발화한다. |
| 단체채팅 범위 | MVP group chat은 최대 2명의 사람과 각 사람이 데려온 캐릭터 최대 2개가 함께 참여하는 2:2를 최대 범위로 둔다. |
| 친밀도 단계 | 캐릭터는 생성 시 lv1-lv4 친밀도 단계를 설정할 수 있으며, 신규 관계는 lv1에서 시작한다. |

## 핵심 데이터 형태

| 데이터 | 사용 목적 | 주요 항목 |
| --- | --- | --- |
| 사용자 프로필 | 사용자의 기본 신원과 서비스 설정을 관리한다. | 표시 이름, 닉네임, 프로필 이미지, 관심 장르, 선호 언어, 연령대, 공개 범위, 요금제 |
| 제공 캐릭터 | free 사용자를 포함한 모든 사용자가 바로 대화할 수 있는 플랫폼 제공 캐릭터를 관리한다. | 이름, 캐릭터 이미지, 소개, 성격, 사용 가능 플랜, 공개 상태 |
| 사용자 캐릭터 | plus 이상 사용자가 직접 만든 캐릭터를 관리한다. | 이름, 캐릭터 이미지, 말투, 성격, 공개 범위, 친밀도 단계, 소유자 |
| 그룹 방 | 사람과 캐릭터가 함께 참여하는 단체채팅 공간을 관리한다. | 방 이름, 대표 이미지, 태그라인, 장르, 참여자, 캐릭터, 공개 범위 |

## 기능 명세서

| 대분류 | 소분류 | 기능 이름 | 설명 |
| --- | --- | --- | --- |
| 온보딩 | 최초 진입 | 제품 소개 화면 | 사용자는 첫 진입 시 Bias가 캐릭터와 1:1 chat 또는 group chat을 할 수 있는 서비스임을 확인하고, 결과로 지갑 연결, 제공 캐릭터로 시작하기, pricing 보기, 내 캐릭터 만들기 진입점을 선택할 수 있으며, plus가 아닌 사용자가 캐릭터 생성을 선택하면 pricing 안내를 본다. |
| 온보딩 | 지갑 연결 | Sui 지갑 연결 | 사용자는 연결할 Sui 지갑을 선택하고 연결을 승인하며, 결과로 Bias 계정 생성 또는 기존 계정 로그인이 진행되고, 연결을 취소하거나 실패하면 재시도 안내와 제공 캐릭터 둘러보기 선택지를 본다. |
| 온보딩 | 프로필 초기화 | 기본 사용자 프로필 생성 | 사용자는 표시 이름, 닉네임, 프로필 이미지(선택), 한 줄 소개(선택), 관심 장르, 선호 언어, 생년 또는 연령대, 프로필 공개 범위, 개인정보 수집 및 이용 동의를 입력하고, 결과로 마이페이지와 채팅 리스트에 사용할 기본 프로필이 생성되며, 필수값 누락, 닉네임 중복, 허용 길이 초과, 동의 누락 시 저장 전에 오류 메시지를 본다. 관심 장르는 추천에 사용할 취향 정보이며 로맨스, 판타지, 학원, 일상, 아이돌/엔터, 게임, 스포츠, 미스터리, 힐링, 기타 중 복수 선택할 수 있고, 선호 언어는 kr 또는 en 중 하나를 선택한다. |
| 온보딩 | 캐릭터 게이트 | 플랜별 캐릭터 접근 | free 사용자는 캐릭터 생성 대신 제공 캐릭터 목록과 plus 업그레이드 안내를 보고, plus 사용자는 직접 만든 캐릭터와 플랫폼 제공 캐릭터를 모두 사용할 수 있다. plus 사용자가 캐릭터 2개를 이미 만든 경우 추가 생성 버튼은 비활성화된다. |
| 발견 | 그룹 피드 | 추천 그룹 방 목록 | 사용자는 공개 group chat을 최근 인기, 장르, 즐겨찾기, 활성 참여자 기준으로 탐색하고, 결과로 방 이름, 멤버 아바타, 한 줄 태그라인, 장르, 참여 가능 여부가 담긴 카드를 본다. 방이 최대 인원에 도달한 경우에만 참여 불가 상태로 표시하고, 그 외의 공개 방은 입장 CTA를 제공한다. |
| 발견 | 그룹 피드 | 장르·정렬 필터 | 사용자는 장르와 정렬 기준을 선택해 group chat 목록을 좁히고, 결과로 조건에 맞는 방만 표시되며, 결과가 없으면 필터 초기화와 그룹 방 생성 CTA를 본다. |
| 발견 | 그룹 피드 | 검색 | 사용자는 방 이름, 해시태그, 멤버 이름, 제작자, 키워드로 group chat을 검색하고, 결과로 검색어와 관련된 방 카드가 표시되며, 검색어가 너무 짧거나 결과가 없으면 안내 문구와 추천 필터가 표시된다. |
| 발견 | 캐릭터 피드 | 멤버 단독 탐색 | 사용자는 플랫폼 제공 캐릭터, 공개 캐릭터, 내 캐릭터를 캐릭터 피드에서 탐색하고, 결과로 이름, 캐릭터 이미지, 한 줄 성격, 소속 group chat 수, 공개 상태, 제공 캐릭터 또는 내 캐릭터 배지를 확인한다. |
| 발견 | 캐릭터 피드 | 검색과 필터 | 사용자는 이름, 태그, 제작자, 성격 키워드와 제공 캐릭터, 공개 캐릭터, 내 캐릭터 필터로 캐릭터를 찾고, 결과로 1:1 chat 시작 또는 group chat 추가 CTA를 보며, 접근 권한이 없는 캐릭터는 상세 진입 전에 제한 사유가 표시된다. |
| 그룹 생성 | 페이지 진입 | 그룹 방 생성 시작 | 사용자는 하단 + 버튼 또는 피드 CTA에서 그룹 방 생성 페이지를 열고, 결과로 방 프로필, 캐릭터 구성, 공개 범위를 입력할 수 있으며, free 사용자는 제공 캐릭터만 선택할 수 있다. 그룹 방은 채팅 형태이므로 별도 시나리오 시작 설정은 제공하지 않는다. |
| 그룹 생성 | 프로필 | 그룹 프로필 입력 | 사용자는 방 대표 이미지, 방 이름, 태그라인, 소개 문구, 장르, 해시태그, 크리에이터 노트를 입력하고, 결과로 피드 카드 미리보기를 확인하며, 방 이름 누락, 글자 수 초과, 부적절한 표현 입력 시 저장할 수 없다. |
| 그룹 생성 | 참여자 | 참여자와 캐릭터 추가 | 방장은 그룹 방에 사용할 캐릭터 슬롯과 입장 가능 인원을 설정하고, 결과로 다른 사용자가 그룹 피드에서 방을 탐색해 직접 입장할 수 있다. 친구 선택은 필수가 아니며, MVP에서는 입장한 사람 2명과 각자의 캐릭터 2명을 넘으면 더 이상 참여할 수 없다. |
| 그룹 생성 | 기타 | 게시 범위와 입장 코드 | 방장은 공개 또는 비공개를 선택하고, 결과로 두 유형 모두 그룹 피드에 노출된다. 공개 방은 바로 입장할 수 있고, 비공개 방은 입장 코드 입력 후 입장할 수 있다. 비공개 방을 만들면 대문자 영어와 숫자로만 구성된 8자 랜덤 입장 코드가 생성되며, 사용자가 입장할 때 입력한 코드가 형식에 맞지 않거나 일치하지 않으면 오류 메시지를 본다. |
| 그룹 생성 | 완료 | 그룹 방 저장 | 사용자는 필수 입력을 마치고 방을 저장하며, 결과로 active group chat이 생성되고 참여자에게 입장 화면이 표시되며, 필수 정보 누락, 캐릭터 제한 초과, 정책 미동의 상태에서는 완료 버튼이 비활성화된다. |
| 캐릭터 | 캐릭터 생성 | 기본 정보 입력 | plus 사용자는 캐릭터 생성 페이지에서 이름, 캐릭터 이미지(선택), 한 줄 소개, 말투, 성격, 공개 범위, 금지 주제, 친밀도 lv1-lv4를 입력하고, 결과로 본인 소유 캐릭터가 생성되며, free 사용자, plus 한도 초과 사용자, 필수값 누락 사용자는 저장할 수 없다. |
| 캐릭터 | 캐릭터 생성 | 캐릭터 말투와 성격 설정 | 사용자는 캐릭터가 자주 쓰는 표현, 대화 톤, 관계 태도, 좋아하는 주제, 피해야 할 주제를 입력하고, 결과로 1:1 chat과 group chat에서 같은 캐릭터성이 유지되며, 부적절한 표현이나 서로 충돌하는 설정은 저장 전에 수정 안내를 받는다. |
| 캐릭터 | 제공 캐릭터 | 플랫폼 제공 캐릭터 사용 | free 사용자는 제공 캐릭터를 선택해 1:1 chat과 제한된 group chat을 시작하고, 결과로 즉시 대화방에 입장하며, 제공 캐릭터는 사용자가 수정하거나 삭제할 수 없다는 안내가 상세 화면에 표시된다. |
| 캐릭터 | 캐릭터 상세 | 캐릭터 상세 보기 | 사용자는 캐릭터 상세에서 설명, 제작자, 공개 범위, 소속 group chat, 1:1 chat 시작, 그룹에 추가 버튼을 확인하고, 결과로 접근 가능한 대화로 이동하며, 비공개 캐릭터는 소유자와 초대받은 사용자에게만 보인다. |
| 캐릭터 | 캐릭터 수정 | 설정 수정 | 캐릭터 소유자는 이름, 캐릭터 이미지, 소개, 말투, 성격, 공개 범위, 금지 주제를 수정하고, 결과로 다음 대화부터 변경된 설정이 반영되며, 소유자가 아니거나 제한 상태인 캐릭터는 수정할 수 없다. |
| 캐릭터 | 캐릭터 삭제 | 삭제와 비활성화 | 캐릭터 소유자는 캐릭터 삭제를 요청하고, 결과로 캐릭터가 목록과 새 방 추가 화면에서 숨겨지며, 이미 진행 중인 방에서는 삭제 안내가 표시되고 복구 가능 기간이 지나면 되돌릴 수 없다. |
| 마이페이지 | 계정 | 내 프로필 보기 | 사용자는 마이페이지에서 표시 이름, 닉네임, 프로필 이미지, 관심 장르, 선호 언어, 공개 범위, 가입일, 현재 요금제를 확인하고 수정하며, 관심 장르는 로맨스, 판타지, 학원, 일상, 아이돌/엔터, 게임, 스포츠, 미스터리, 힐링, 기타 중 복수 선택하고 선호 언어는 kr 또는 en 중 하나로 설정한다. 필수값 누락 또는 닉네임 중복 시 저장할 수 없다. |
| 마이페이지 | 그룹 관리 | 내 그룹 방 목록 | 사용자는 자신이 만든 group chat의 공개 상태, 멤버 수, 최근 대화 시각을 확인하고, 결과로 상세 보기, 수정, 삭제, 공유로 이동하며, 삭제 예정 방은 새 입장이 제한된다. |
| 마이페이지 | 캐릭터 관리 | 내 캐릭터 목록 | 사용자는 본인이 만든 캐릭터와 제공 캐릭터 사용 내역을 구분해 보고, 결과로 캐릭터 상세, 수정, 삭제, 1:1 chat 시작으로 이동하며, free 사용자는 직접 만든 캐릭터 영역 대신 plus 안내를 본다. |
| 마이페이지 | 기억 관리 | 대화 기억 요약 보기 | 사용자는 캐릭터 또는 그룹 방별로 저장된 대화 기억 요약과 마지막 반영 시각을 확인하고, 결과로 기억 사용 여부를 켜거나 끌 수 있으며, 민감한 내용으로 판단된 항목은 요약 없이 비공개 처리 안내만 표시된다. |
